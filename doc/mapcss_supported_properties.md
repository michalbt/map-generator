# Supported MapCSS Properties

| Property Name | Type | Applies to |
|-|-|-|
| `fill-color` | `Color` | canvas, line/area objects |
| `fill-opacity` | `Float` | canvas, line/area objects |
| `fill-image` | `Url` | canvas, line/area objects |
| `z-index` | `Integer` | line/area objects |
| `width` | `Float` | line/area objects |
| `color` | `Color` | line/area objects |
| `opacity` | `Float` | line/area objects |
| `dashes` | `IntegerList` | line/area objects |
| `casing-width` | `Float` | line/area objects |
| `casing-color` | `Color` | line/area objects |
| `casing-opacity` | `Float` | line/area objects |
| `casing-dashes` | `IntegerList` | line/area objects |
| `icon-opacity` | `Float` | point objects |
| `icon-image` | `Url` | point objects |
| `icon-width` | `Float \| Percentage` | point objects |
| `icon-height` | `Float \| Percentage` | point objects |
| `font-size` | `Integer` | line/area objects, point objects |
| `max-width` | `Float` | line/area objects, point objects |
| `font-weight` | `FontWeight` | line/area objects, point objects |
| `font-style` | `FontStyle` | line/area objects, point objects |
| `font-variant` | `FontVariant` | line/area objects, point objects |
| `text-decoration` | `TextDecoration` | line/area objects, point objects |
| `text-transform` | `TextTransform` | line/area objects, point objects |
| `text` | `TagKey` | line/area objects, point objects |
| `text-color` | `Color` | line/area objects, point objects |
| `text-opacity` | `Float` | line/area objects, point objects |
| `text-position` | `TextPosition` | line/area objects, point objects |
| `text-offset` | `Float` | line/area objects, point objects |
